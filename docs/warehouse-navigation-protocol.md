# Locked warehouse-route proof-of-concept protocol

Locked  before any new warehouse simulation or training. This is an isolated toy navigation branch, not a robot deployment or a modification of Fly Hero RPS. Hypothesis: a reward-trained Fly A's preferred navigation move, transmitted as measured DNge175 spikes, makes Fly B reach a retained delivery policy earlier than silence, untrained, state-shuffled, and generic neural messages. A pass would establish only this small route and engineered hybrid controller.

## Environment and information

Use a 5×5 grid. Each layout is a translation of the same four-cell route: start `S=(1,1)`, junction `J=(2,1)`, junction `K=(2,2)`, delivery bay `G=(1,2)` plus the layout offset. Every other tile is a shelf/obstacle. An internal wall blocks the direct S→G edge. Actions are **0 east, 1 north, 2 west**. From S, east advances to J; from J, north advances to K and west returns to S; from K, west delivers to G. Other attempted moves collide and leave the robot in place. Reward is **+0.4** for forward progress, **+1** for delivery, **−0.4** for J→S, **−0.8** for collision, and an additional **−0.3** at the final step of an episode without any delivery. Each episode has exactly **four action decisions**. After delivery, a new package starts from that episode's predetermined initial cell at the next decision; this keeps every arm's action and own-reward update budget identical. An episode counts as successful if it makes at least one delivery. Log total deliveries and collisions separately.

The only observation passed to either controller is the visible location marker: S→cue **2**, J→cue **0**, K→cue **1**; G is terminal and never a decision state. The cue stimulates its existing VPN lane's `.slice(2)` neurons at **150 Hz**. The policy is not given coordinates, the layout offset, goal direction, transition table, action answer, or reward before choosing. The physical location marker is not numerically the optimal action. A memoryless policy is sufficient: fixed actions east/north/west reach G from S/J/K in 3/2/1 moves, within the four-decision horizon. The S→G wall prevents a one-step shortcut. This is a deliberately small topological route, close to a three-state contextual task; it does not validate arbitrary path planning.

Initial training layouts have offsets `(0,0)` and `(1,0)`, each with **18 episodes**, six starts at each of S/J/K; order is shuffled once using `rng(2026110801)` (confirmation `rng(2026110803)`). Frozen evaluation uses the translated held-out layout `(0,1)` with **12 episodes**, four starts at each state, shuffled using `rng(2026110802)` (confirmation `rng(2026110804)`). These are position translations of the *same topology*, not novel obstacles. Layout, initial state, episode length, and step-indexed neural/action RNG keys are fixed across arms. Different visited states are a consequence of their actions, not a chosen condition.

## Neural and learning protocol

Initial teacher/student neural identities are **13001/13002**; confirmation, only after full initial pass, **13003/13004**. An exact-number search found no earlier use in research docs/runners. Each fresh teacher trains on **36×4=144 own-reward decisions** with the existing three-MBON `RpsContextualBandit` (`alpha=.03`, `epsilon=.20`, zero initial Q, fixed archived RPS MBON feature mean/std, frozen KC→MBON multipliers). No optimal-action targets are passed to training. Each student has the existing VPN-routed `ChallengeCueHeadBandit` plus the unchanged post-reward decoded-action imitation update (`.03` softmax gradient) only when a message arrives. Student own-reward selected-action update is `.03`, exploration `.20`. Neither fly copies weights. This reuses the RPS controller equations on navigation rewards; reward magnitude/route are the task adaptation.

Teacher training uses the existing **400 ms** decision cycle: cue 0–240 ms, ordinary count reset at 50, choice/reward at 240, dopamine/readout update at 340, end at 400. Fresh keyed neural and action random streams are assigned per episode and step. Frozen teacher evaluation uses identical timing with exploration and learning off.

The trained teacher is frozen after pretraining. For each step key and visible state, reward-free teacher inference is prerecorded from a real neural probe; this table is needed because different student policies visit different locations. The teacher receives the same visible marker, never the hidden optimal move. The trained arm selects the table entry for Fly B's current public marker. The **state-shuffled** arm selects the fixed cyclically shifted marker `(state+1)%3` from the same measured teacher table, breaking state alignment without changing teacher weights or the neural message code. This is a state shuffle, not a matched global trial permutation; report its actual preference histogram and alignment. The untrained arm uses a zero-Q teacher on the same visible marker; the generic arm uses `rng(2026110805)` (confirmation `rng(2026110806)`) to select a cue-independent action. The no-message arm receives no pulse or imitation. Every messaged student gets exactly **144** pulses and imitation opportunities. Teacher inference is frozen and prerecorded, not simultaneous teacher reward learning.

At each student decision, reset only that student's neural state, stimulate its location VPN during **0–240 ms**, reset spike counts at **50 ms**, then select its own action at **240 ms** using the ordinary cue-head/Q readout. Stimulate DN **3141/3165** at **300 Hz, 240–280 ms** with codes `(1,0)/(0,1)/(1,1)` for preferred actions 0/1/2. Count actual DN spikes during that window; at **280 ms** decode the measured counts, execute Fly B's already chosen move, and give its own navigation reward. At **620 ms** run the ordinary own-reward update, followed by the existing `.03` decoded-action imitation update. End at **680 ms**. The source preference selects stimulation targets only; Fly B's imitation method receives its **decoded spike action**, never a raw teacher target. Neural dynamics, connectome, dopamine rule, RPS default game, and demo are unchanged.

## Sequential gates, measurements, and stops

1. **Environment before neural training.** Enumerate the three starts and verify that the memoryless east/north/west route delivers in at most 3 moves, every alternative edge has the documented collision/backtrack behavior, every start/layout stays in bounds, starts and layouts are balanced, and no observation includes an optimal-action field. Failure stops.
2. **Frozen sensory representation.** Initial seed 13002 (confirmation 13004), cues 0/1/2 × six calibration and six disjoint held-out keys. Fit only an analytical nearest-centroid rule on the **three standardized pooled MBON rates** from calibration; on held-out require **≥14/18 overall and ≥4/6 per cue**, while the actual VPN-count cue router must identify **6/6 per cue**, with finite features, distinct centroids, and unchanged weights. The analytical rule is never installed in a policy. Failure stops before teacher training.
3. **Teacher.** Train the predetermined teacher once for 144 decisions. Frozen disconnected evaluation on the 12 held-out episodes must yield **≥9/12 successful episodes**, **≥2/4 per start**, and at least **four uses of each action**; controller weights must change and neural multipliers stay one. On the fixed reward-free source table, score the **first 12 step keys for each state**; the trained preference must match the analytically optimal route move on **≥9/12 probes per state** and use all three actions. The optimal action is used only for post hoc source scoring. Failure stops.
4. **Receiver.** For the student, on each cue and six matched keys compare no pulse and all three forced codes: **72 probes**. Require actual intended DN spikes, zero unstimulated DN spikes, correct **6/6** decode per cue/code, no-message counts zero, **6/6** VPN routing, exact paired pre-pulse MBON features, and unchanged weights. Failure stops.
5. **Independent student and controls.** The no-message student starts **≤6/12** successful frozen episodes and finishes **≥9/12**, **≥2/4 per start**, with all three actions used, after 144 own-reward decisions. A synthetic decoded target must raise its margin and disabled imitation leave weights unchanged. Fix state-shuffled and generic streams before advised training; after their runs, require each to cover all actions and match the route-optimal action on **≤50% of its actually visited states**. This is a control-validity gate, not a reason to resample. If a validity gate fails, stop and report the run. Record all control source/action histograms and actual state exposures.
6. **Five-arm initial comparison.** Run trained, no message, untrained, state-shuffled, and generic with identical initial student weights, 36 training episode starts/layouts, 144 action and own-reward opportunities, and keyed streams. Independently freeze/evaluate all arms on the same 12 held-out episodes after **0,3,6,12,24,36** training episodes with no exploration, teacher message, reward update, or imitation. Save each step and each episode's success, delivery, collision, neural features, action scores, reward, DN counts, decoded action, controller updates, and unchanged KC→MBON multipliers. Primary measure is mean successful episodes/12 at checkpoints **3/6/12/24**. Trained advice passes only if that mean exceeds **each** control by **≥2/12**, first reaches **≥9/12 by checkpoint 12** at an earlier sampled checkpoint than every control, and finishes **≥9/12 with ≥2/4 per start**. Ties fail. Secondary measures: collisions, total deliveries, final disconnected success, message accuracy, and action counts.

Only if **every** initial gate passes, run one independent confirmation using the fixed 13003/13004 identities, shuffled starts, and generic stream, with the same budgets and gates. Any failed prerequisite or comparison stops immediately; no architecture, parameter, code, or threshold search follows. Save a new write-once `data/warehouse_navigation_{initial,confirmation}.json` for each started stage. The result is not evidence of real robot safety, geometry generalization, or a necessary DN-output connectome edge. The earlier RPS neural-versus-digital ablation remains applicable as a limitation.
