# Locked synthetic sensor-classification protocol

Locked  before generating the new data or running neural probes. This is an isolated, opt-in benchmark. Earlier RPS results, the demo, and the connectome are unchanged. The hypothesis is that a teacher trained on its own labeled examples can transmit a class preference through measured DN spikes and improve a student's **early frozen, teacher-disconnected** classification accuracy beyond four matched controls. A passing pilot would be narrow evidence for this synthetic task, not an industrial result or a connectome advantage over digital delivery.

## Dataset and input

Three equally frequent latent classes generate continuous `(temperature °C, vibration mm/s)` pairs. Independent Gaussian coordinates are sampled with Box–Muller and rejected until they lie within temperature `[35,85]` and vibration `[0,10]`; values retain full precision. Normal has mean `(50,2.2)` and standard deviations `(8,1.6)`; overheating `(71,2.5)`, `(8,1.6)`; excessive vibration `(51,7)`, `(8,1.6)`. Distributions overlap. Each split has an equal number of examples per class and a seed-driven permutation. No example is reused across splits; exact duplicate pairs stop the run. The class index is never an input feature. A wrong prediction gives reward `−1`, a correct one `+1`; reward uses the label only after the prediction.

Use existing VPN lane 0 for temperature and lane 1 for vibration, stimulating each lane's `.slice(2)` neurons simultaneously during `0–240 ms`. Fixed rates are `40 + 3×(temperature−35)` Hz and `40 + 15×vibration` Hz, both within `[40,190]`. Lane 2 is off. This gives each *sensor*, not each class, a fixed pathway; neither the generating class, target action, hidden sample index, nor future reward controls the drive. The three existing action-group MBON rates, counted after the ordinary `50 ms` reset, are the only teacher/student policy features. Apply `log1p` and per-feature mean/std fitted on the unlabeled calibration neural responses (std floor `0.05`); freeze these values before held-out probes and training. The three-feature existing `RpsContextualBandit` is used as one three-class head, without VPN cue routing because both channels are simultaneously active. Its original `alpha=.03`, `epsilon=.20`, selected-action reward update, and frozen KC→MBON weights remain unchanged.

Exact-number searches of existing documentation and runners found no use of these identities before this protocol. Each sample uses a keyed neural RNG and action RNG; arms receive the same initial weights, samples, and streams. The same 36 student evaluation examples are reused at every checkpoint, in independent frozen network/controller copies, never for training or parameter choices. Confirmation uses disjoint data and neural identities. A raw-sensor nearest-centroid comparator is analytical only and never installed in a fly.

## Sequential validity gates and stop rules

1. **Sensory representation, before training.** Simulate 72 calibration and 36 held-out samples, reward-free, with independent calibration and student neural seeds. Fit nearest Euclidean class centroids from standardized calibration MBON rates only, then freeze. On held-out samples require at least **26/36** correct overall, **7/12** per class, finite nonconstant MBON features (at least two varying components), and exact repeatability of one keyed probe. The same centroid rule on standardized raw sensor values must also reach **26/36 and 7/12 per class** to show that the dataset itself is learnable. Record all probes. Any failure stops before teacher or student training. This analytical decoder is a feasibility measurement, never the trained policy.
2. **Teacher.** Train one fresh teacher for **96 examples**, using only its own simulated three-MBON features, sampled/greedy class choice, and post-choice `±1` reward. No class target enters the controller. Frozen, greedy, nonlearning evaluation on 36 separate examples must reach **at least 24/36**, **7/12 per class**, and choose all three classes at least six times. Neural weights remain one. Failure stops.
3. **Receiver and source.** On one fixed held-out sensor example per class, use six keyed repeats for each forced DN code `Rock/class 0=(3141 on,3165 off)`, `class 1=(off,on)`, `class 2=(on,on)`, plus no-message controls. Student sensory features at 240 ms must exactly match paired no-message trials, all 54 forced messages decode from actual `240–280 ms` DN spikes, intended cells spike and off-target cells remain silent, no-message counts stay zero, and neural/controller weights stay fixed. The frozen teacher then makes a continuous-state, reward-free preference tape for all 96 student-training examples from its own MBON-driven Q scores. Require **at least 67/96** label agreement, **19/32 per class**, and all three preferred actions. This label check is analysis only. Failure stops.
4. **Independent student and mechanism.** The no-message student starts at **at most 20/36** frozen and after 96 own-reward examples reaches **at least 22/36**, **6/12 per class**, with all three classes chosen. A decoded-target synthetic update must increase the target margin, while disabled imitation leaves weights unchanged. KC→MBON multipliers remain one. Failure stops before the advised comparison.
5. **Controls before advised training.** Globally shuffle the trained teacher's 96-preference tape once with `rng(610011)`, preserving its histogram; require at least 48 positions moved. Generic advice is independently uniform from `rng(610012)`. Both must emit all three classes and agree with the training labels on **at most 16/32 per class**. No reseeding if a control fails. Untrained teacher uses zero Q and real sensory inference. Silence has no DN pulse or imitation; the other four arms get exactly one measured neural message and one decoded-action imitation opportunity per example. All arms get identical labeled examples and their own reward. Failure stops.
6. **Five-arm pilot.** Run `trained`, `alone`, `untrained`, `shuffled`, `generic` for the same **96 examples**. Preserve the post-sensory schedule: sensor `0–240 ms`, choice and teacher preference at 240, DN stimulation `240–280 ms` at **300 Hz**, reward at 280, own-reward `.03` update and decoded-action softmax imitation `.03` at 620, end at 680. Each student resets its neural state between examples; the teacher source tape keeps a continuous neural state. Preference chooses only DN targets. The imitation call receives **decoded DN counts only**, never a raw teacher preference or true label. Frozen evaluations at **0, 6, 12, 24, 48, 96** use all 36 independent examples, no DN message, no exploration, no learning. Save trial-level training and all frozen rows, weights, measured DN counts, class confusion, and update counts. The trained arm passes only if its mean correct/36 over checkpoints **6/12/24/48 exceeds every control by at least 3**, it first reaches **25/36 by checkpoint 48 and earlier than every control**, and ends at **at least 25/36 and 7/12 per class**. All validity gates also must pass. Ties and any failure fail the stage.

Only after every initial gate passes, repeat **once** with the fixed confirmation identities, data, and identical rules. A confirmation failure is preserved; no tuning, seed replacement, threshold change, or further run. Raw artifacts are write-once `data/sensor_classification_{initial,confirmation}.json`. The report must separate pilot from confirmation, include every stopped stage, and state that the prior RPS digital-delivery ablation found no neural advantage.
