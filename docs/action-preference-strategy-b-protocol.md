## Feasibility and hypothesis

Use existing deterministic `Opponent({strategy:'previous_opponent', offset:2, noise:0})`. On an observed previous opponent move `c`, the next move is `(c+2)%3`; the winning student action is `c`. Neither fly receives the strategy identity, future move, or correct action. The ordinary previous-move VPN cue therefore suffices after each episode's first cue-free round. The selected untouched opponent schedules visit all three cues: pilot training **93/90/93**, confirmation training **93/91/92**, and each 72-round evaluation **23/23/23**. These counts came from opponent-code inspection alone, before neural training.

Hypothesis: an independently reward-trained Strategy B teacher's MBON-driven preferred action, encoded through measured DN spikes, produces a retained **early** learning-speed advantage over silence, untrained, globally shuffled, and generic advice under the same fixed student architecture. A pass supports this one task, not universal teaching or original dopamine-only transfer.

## Unchanged teacher, neural message, and student

- Teacher: the existing three standardized MBON features and `RpsContextualBandit`, zero-initialized, alpha **0.03**, epsilon **0.20**, 12 episodes × 24 RPS rounds of **own-reward** training using existing `RpsEpisode` (400 ms per round). KC→MBON synapses frozen. Three 24-round independent frozen games with exploration and learning off. No strategy label or answer enters teacher policy. Then freeze its controller for a 680 ms continuous-state, reward-free inference tape on the stage's student training opponent sequences; `game.play(0)` advances this opponent only, as in the original architecture. Strategy B does not depend on player action. Teacher preference is the lowest-index argmax of its own simulated MBON-driven Q scores, never a correct-action label.
- Message: the existing three-pattern code `Rock 0=(DN3141 on,3165 off)`, `Paper 1=(off,on)`, `Scissors 2=(on,on)` at **300 Hz, 240–280 ms**. Fly B records actual spikes from both DN neurons and decodes `(+,0)/(0,+)/(+,+)`. `(0,0)` means no message. The source preference is used only to select stimulation targets and for analysis assertions; Fly B's learning update receives its own decoded spike message.
- Student: the unchanged `ChallengeCueHeadBandit` VPN-routed cue heads with the original three standardized MBON features and zero initial weights; alpha **0.03** selected-action own-reward update, epsilon **0.20** training exploration, and **0.03** post-reward decoded-action softmax imitation update. KC→MBON multipliers stay at one. Student neural state resets between rounds. Cue is sensed at **0–240 ms**, ordinary count reset **50 ms**, decision and teacher source preference at **240 ms**, DN pulse **240–280 ms**, own action/reward at **280 ms**, own-reward then imitation updates **620 ms**, round end **680 ms**. Message does not change that round's played action. Preserve feature normalization, connectome, dynamics, and learning equations exactly.

## Sequential gates and stop rules

1. **Teacher:** frozen wins **≥58/72**, **≥70% per observed cue**, and at least **12 selections of each RPS action** across 69 observed evaluation rounds; neural synapses unchanged. Stop if any fail.
2. **Receiver:** for the predetermined student, run cues 0/1/2 × repeats 0–11 × no-message/forced action 0/1/2, **144 frozen reward-free probes**. Every forced code must decode **12/12 per cue** from actual DN counts, selected targets spike and unselected targets stay zero, no-message counts zero, VPN route **12/12** for every cue/condition, and pre-pulse MBON rates/features and route exactly match paired no-message probes. Controller and synaptic weights unchanged. Report the old external pooled decoder descriptively; it is not the actual cue-head gate. Stop if any fail.
3. **Student mechanism and independent learning:** the same synthetic decoded-target test must increase target margin while disabled imitation leaves weights unchanged. The no-message arm starts at **≤50/72**, reaches **≥58/72** final, **≥70% per cue**, and **≥12 selections of each action** among 69 observed evaluation rounds after the fixed **12×24** training budget. Stop if any fail; no favorable student replacement.
4. **Source and control validity before advised-student training:** teacher preference wins **≥70% per observed cue** and emits all three actions. Use a single global Fisher–Yates shuffle of the 276 observed teacher preferences with fixed `rng(2026110702)`, preserving its exact action histogram; at least **50%** of observed positions must change. Generic messages are one independently sampled action per observed round from `rng(2026110703)`, independent of cue/outcome/reward and matching exposure, not necessarily action histogram. Shuffled and generic tapes must each contain all three actions and have **≤60% correct-action coincidence per cue** on this predetermined training schedule. Untrained teacher has zero Q and uses real neural inference. Stop on failure; never reshuffle or replace the generic stream.
5. **Five-arm comparison:** `trained`, `alone`, `untrained`, `shuffled`, `generic`, each **12×24** rounds. Every messaged arm gets exactly one actual DN stimulation and decoded imitation opportunity on each of the **276 observed-cue rounds**; Alone gets none. Keep all arms' own reward learning and all keyed streams matched. Evaluate independent frozen simulator/controller copies at **0,6,12,24,48,96,288** student updates on the same stage-specific 72 held-out rounds, with no teacher message, exploration, or learning. Save **trial-level frozen evaluation rows** (cue, action, opponent move, reward, measured features/scores and DN counts), all training rows, message counts, update counts, final controller weights, KC→MBON integrity, and all numerical gates.
6. **Primary teacher-specific pass:** trained advice reaches **≥58/72 by checkpoint 48** at a strictly earlier *sampled* checkpoint than **each** control and exceeds **each** control by **≥4 wins/72 in the mean** over frozen checkpoints **6,12,24,48**. Its final disconnected policy reaches **≥58/72**, **≥70% wins per observed cue**, and at least **12 choices of every action** among observed rounds. Ties or any source, receiver, independent-learning, weight-integrity, exposure, or frozen-evaluation gate failure mean the stage fails. Report every arm and failure, regardless of outcome.

Only if the entire initial stage passes may the separately locked confirmation pair run **once** under these same gates with its own predetermined opponent sequences. Failure at any prerequisite or comparison stops; no architecture, code, stimulation, budget, seed, threshold, or control changes are allowed in response. Save a separate **write-once** result for each started stage under `data/rps_action_preference_strategy_b_{initial,confirmation}.json`. A two-stage pass would support independent-seed and independent-sequence Strategy B replication for this engineered hybrid protocol, not broader opponent generalization or biological teaching.
