# Prospective independent KC-based Fly A recovery learning

**Locked  before reward training.** This is a separate experiment following the reward-free [KC information study](practical-transfer-kc-information-report.md). The failed 42-MBON sensory gate and all older recovery/RPS results remain unchanged. The sole new learning input is the **previously validated 42-feature KC bucket summary**; the synthetic task and controller are copied unchanged from the [practical-transfer redesign](practical-transfer-redesign-protocol.md).

## Hypothesis and matched design

The fixed KC population summary may retain enough continuous telemetry for the existing reward-only Bayesian ridge controller to learn the three synthetic recovery choices from selected-action outcomes. Passing an analytical reconstruction gate did not establish this. Compare KC Fly A with a matched raw-observable learner on the same case/outcome tapes and controller random stream. The raw arm is an observational upper reference, not neural teaching. Neither receives a hidden cause, optimal action, unchosen outcome, future reward, or reconstructed ground-truth input. The neural controller receives only measured KC counts after the existing VPN→KC simulation.

## Unchanged task, feedback, and case tape

Each one-attempt episode observes continuous `(offset, slip, resistance)` in `[0,1]^3`. The action success probabilities, costs, delays, escalation, and net reward are **exactly** the formulas in the redesign protocol: `p0=sigmoid(1.6+1.2o−1.5s−2b)`, `p1=sigmoid(1.3−.6o+2s−1.7b)`, `p2=sigmoid(.4−.3o−.5s+3.3b)`; cost `[.06,.12,.31]`, delay `[2,4,7]`, selected net reward `(success ? 1 : −.4) − cost[action]`. The learner sees only its selected action's realized outcome and reward. Known synthetic probabilities may be used **after decisions for analysis only**.

Use the repository `rng(seed)` and the original tape construction: shuffle the eight octants independently in each of twelve 24-case blocks; within each octant draw three independent continuous cases. For each case draw the three coordinates in offset/slip/resistance order and all three potential Bernoulli outcomes in action order. Force actions `(positionWithinOctantTriple + blockNumber) mod 3`, so the first **288** attempts guarantee **12 selected outcomes per octant/action**, independent of reward. Shuffle **24 further cases per octant** for the final **192** free attempts. The evaluation tape has **15 independent cases per octant**, shuffled, for **120** held-out cases. Initial tapes are copied byte-for-byte from the archived raw artifact; confirmation tapes follow the same generator with the fixed new seeds. Raw and KC arms share each stage's tape and controller seed but use separate controller RNG instances. Each free decision consumes exactly three Gaussian draws; coverage and frozen evaluation consume none. No outcome is selected based on either arm's policy.

## Neural input and unchanged controller

For each KC attempt, fully reset the original real-wiring network, key its random stream as `neuralSeed × 10^7 + phase × 10^6 + index × 1000 + 1` (phase 2 train, 3 held-out), and simultaneously stimulate `laneVpn[j].slice(2)` at `40+110×telemetry[j]` Hz from 0–240 ms. Reset counts at 50 ms; read actual KC counts at 240 ms; stop drives. Use the same 50–240 ms measurement as the KC information study. KC→MBON synaptic multipliers remain one. Precompute held-out neural features once from a separate simulator instance, then reuse that fixed tape for checkpoints 0/288/480. Check effective RNG keys do not collide.

The exact 42-feature summary is fixed: order KCs by `net.idx.kc`; bucket each KC by its **position modulo 42**; sum its measured spike count within the bucket; take `log1p` of each bucket. Compute each bucket's mean and sample standard deviation on **only the archived 96 reward-free 19101 calibration probes**, with SD floor `0.1`. Fly A input is `x=[1,(log1p(bucket_j)−mean_j)/(sd_j×sqrt(42)) for j=0..41]`, dimension 43. No raw telemetry or analytical reconstructed value enters `RecoveryRidge.choose()` or `update()`. The initial and confirmation use the same frozen calibration constants. The raw comparator retains the original four inputs `x=[1,(2o−1)/sqrt(3),(2s−1)/sqrt(3),(2b−1)/sqrt(3)]`.

Reuse `RecoveryRidge` without modification for both arms: each action starts `A=4I, b=0`; predicts mean `xᵀA⁻¹b` and exploration SD `0.7 sqrt(xᵀA⁻¹x)`. During the final 192 training cases, independently sample one normal value per action and choose its highest; during coverage use only the forced action. On the selected reward, update **only** its action's `A+=xxᵀ, b+=reward×x` (existing Sherman–Morrison implementation). Frozen selection uses mean argmax with the existing lowest-index tie rule, without posterior samples, rewards, updates, or messages. Do not change priors, exploration, equations, neural dynamics, or reward model.

## Metrics, gates, stopping

At **0, 288, and 480** attempts, evaluate a frozen snapshot on the same 120 held-out observations and neural feature tape; check parameters and KC→MBON multipliers unchanged during evaluation. Report mean **model-expected** net reward (analysis-only), realized held-out successes, A0/A1/A2 choices, per-octant expected rewards/successes/actions, modeled delay/escalations, and gap against the best constant and observable oracle. Report training actions, selected rewards, failures, delay, escalation, controller parameter changes, KC feature sparsity/range, actual VPN/KC counts, timing and reset metadata. Training realized reward is not frozen policy accuracy.

**Pre-training correctness gate:** archived initial raw tape and raw checkpoints match their saved rows; KC bucket vector has 42 entries and follows the reward-free fixed extraction; input to the controller has 43 finite entries; no raw telemetry enters the neural controller; all 288 coverage actions are outcome-independent; selected-arm-only update and frozen no-update checks pass; a repeated keyed neural probe is identical; simulation multipliers remain one. Stop before training if any fails.

**Initial and confirmation learning gates, each required:** (1) final KC mean expected reward exceeds its own frozen checkpoint 0 by **≥0.05**; (2) exceeds the best constant action on that held-out tape by **≥0.05**; (3) closes **≥50%** of the positive oracle-minus-constant gap; (4) selects each of the three actions **≥12/120** times frozen; (5) is no worse than **0.05 below** its same-tape raw learner's final mean expected reward; (6) controller parameters change from selected rewards, while KC→MBON multipliers remain one and all checkpoint copies remain unchanged. These are the earlier redesign raw/teacher floors, reused without lowering. Report realized recoveries and costs, but do not use their finite-sample variation to rescue a failed expected-reward gate. A nonpositive oracle gap or failed raw reference is invalid and stops the stage.

If any initial correctness or learning gate fails, save the initial result and **do not run confirmation**. Run exactly the preselected confirmation stage only if the initial KC stage passes every gate; apply the identical criteria independently. Any confirmation failure remains a failure, with no seed replacement, parameter tuning, or further training. A passing pair would justify **designing**, not automatically running, a separately locked teacher–student experiment. It would not establish neural communication, biological plasticity, a necessary connectome pathway, or warehouse-robot performance. Save each completed stage in a separate write-once artifact with protocol SHA-256, full trial rows, snapshots, gates, and reproduction command.
