RASPBERRY PI HARDWARE DEMO — COMPLETE BEGINNER GUIDE
=====================================================
For: someone who has never touched a Raspberry Pi
Time to build: 3-4 hours at the hackathon
What you'll have: a physical second "agent" that shows Fly B's
wins in real time, connected to your laptop by a USB cable.
Unplugging the cable physically disconnects the teacher.


===============================================================
WHAT YOU ARE BUILDING AND WHY
===============================================================

Your laptop runs the full simulation.
The Pi is "the other agent" — Fly B.

The USB cable between them IS the 12-byte message channel.
When you unplug it, Fly B loses the teacher signal.
When you plug it back in, teaching resumes.

This makes the concept physical. Judges see two separate machines.
They understand "incompatible systems communicating through
a constrained channel" immediately, without explanation.

The Pi shows one screen:

  ┌─────────────────────────┐
  │  FLY B                  │
  │                         │
  │  Wins: 68 / 72          │
  │  Round: 48              │
  │                         │
  │  ● TEACHER CONNECTED    │
  └─────────────────────────┘

When you unplug:

  ┌─────────────────────────┐
  │  FLY B                  │
  │                         │
  │  Wins: 12 / 72          │
  │  Round: 48              │
  │                         │
  │  ○ learning alone       │
  └─────────────────────────┘

===============================================================
STEP 1 — SET UP THE PI (do this before the hackathon if possible)
===============================================================

This takes about 45 minutes. Do it at home if you can.

1a. DOWNLOAD THE PI IMAGER
    Go to: https://www.raspberrypi.com/software/
    Download "Raspberry Pi Imager" for your OS (Windows/Mac).
    Install it.

1b. FLASH THE SD CARD
    - Insert your microSD card into your laptop
      (use a USB adapter if your laptop has no SD slot)
    - Open Raspberry Pi Imager
    - Click "Choose Device" → select your Pi model
    - Click "Choose OS" → "Raspberry Pi OS (64-bit)"
      (the one that says "Recommended")
    - Click "Choose Storage" → select your SD card
    - Click the gear icon (⚙) BEFORE clicking Write:
        ✓ Set hostname: flyhero
        ✓ Enable SSH
        ✓ Set username: pi
        ✓ Set password: flyhero2026
        ✓ Configure WiFi: enter your phone hotspot name + password
          (you'll want WiFi at the hackathon for setup)
    - Click "Write" and wait ~5 minutes

1c. BOOT THE PI
    - Put the SD card in the Pi (small slot on the underside)
    - Connect HDMI cable to Pi and to a monitor/TV
    - Connect keyboard and mouse via USB
    - Connect the power supply LAST (this turns it on)
    - Wait about 90 seconds for it to boot
    - You should see a desktop

1d. OPEN A TERMINAL
    - Click the terminal icon at the top of the screen
      (looks like a black rectangle with ">_")
    - You'll type all commands here


===============================================================
STEP 2 — WIRE THE OLED DISPLAY
===============================================================

The OLED has 4 pins. You connect them to the Pi's GPIO pins
with jumper wires. GPIO = the row of metal pins on the Pi board.

THE 4 PINS ON THE OLED (labeled on the back of the display):
  VCC  (power)
  GND  (ground)
  SCL  (clock)
  SDA  (data)

WHERE TO PLUG THEM ON THE PI:
  Look at the Pi board. The GPIO pins are the 2 rows of 20 pins
  each along one edge. Count them from the corner nearest the
  SD card slot.

  OLED VCC  → Pi Pin 1  (3.3V power — first pin, corner)
  OLED GND  → Pi Pin 6  (Ground — 3rd pin on outer row)
  OLED SCL  → Pi Pin 5  (GPIO 3 / SCL)
  OLED SDA  → Pi Pin 3  (GPIO 2 / SDA)

PIN MAP (Pi 4, looking at the board with pins facing you,
         SD card slot at the bottom-right):

  [1 ] [2 ]     ← Pin 1 = 3.3V (connect OLED VCC here)
  [3 ] [4 ]     ← Pin 3 = SDA  (connect OLED SDA here)
  [5 ] [6 ]     ← Pin 5 = SCL  (connect OLED SCL here)
                   Pin 6 = GND  (connect OLED GND here)

If you are unsure, search "Raspberry Pi 4 GPIO pinout diagram" —
every result will show the same map. Pinout.xyz is a good reference.

IMPORTANT:
  - Push the jumper wires FULLY onto the pins until they click
  - Double-check VCC goes to 3.3V, NOT 5V (Pin 2)
    5V will fry the display
  - The Pi should be powered OFF when you wire this


===============================================================
STEP 3 — INSTALL SOFTWARE ON THE PI
===============================================================

Do this after wiring the display. Pi should be powered on
and connected to WiFi (from Step 1c setup).

Open the terminal and run these commands one at a time.
Wait for each one to finish before typing the next.

3a. UPDATE THE PI
    sudo apt update
    sudo apt upgrade -y
    [this takes 5-10 minutes]

3b. ENABLE I2C (the communication protocol for the display)
    sudo raspi-config
    
    In the menu that appears:
    → "Interface Options"
    → "I2C"
    → "Yes" to enable
    → "Finish"
    → Reboot if asked

3c. INSTALL PYTHON LIBRARIES
    pip3 install adafruit-circuitpython-ssd1306
    pip3 install pillow
    pip3 install pyserial
    
    [each takes 1-3 minutes]

3d. VERIFY THE DISPLAY IS DETECTED
    sudo i2cdetect -y 1
    
    You should see a grid with "3c" or "3d" somewhere in it.
    That means the Pi found the display. If you see only "--",
    check your wiring.

STEP 4 — PUT THE DISPLAY CODE ON THE PI
===============================================================

4a. CREATE THE SCRIPT
    In the terminal, type:
    nano ~/flyhero_display.py
    
    This opens a text editor. Copy and paste this entire block:

---CUT HERE---
import serial
import time
import board
import busio
from PIL import Image, ImageDraw, ImageFont
import adafruit_ssd1306

# Display setup
i2c = busio.I2C(board.SCL, board.SDA)
oled = adafruit_ssd1306.SSD1306_I2C(128, 64, i2c)
oled.fill(0)
oled.show()

# Serial setup - reads from laptop
# /dev/ttyUSB0 is the USB connection to the laptop
# Try /dev/ttyACM0 if this doesn't work
PORT = '/dev/ttyUSB0'
BAUD = 9600

def draw_screen(wins, total, rounds, connected):
    img = Image.new('1', (128, 64))
    draw = ImageDraw.Draw(img)
    
    # Title
    draw.text((0, 0), 'FLY B', fill=255)
    
    # Wins
    draw.text((0, 18), f'Wins: {wins} / {total}', fill=255)
    
    # Round
    draw.text((0, 32), f'Round: {rounds}', fill=255)
    
    # Connection status
    if connected:
        draw.text((0, 50), '* TEACHER CONNECTED', fill=255)
    else:
        draw.text((0, 50), 'o learning alone', fill=255)
    
    oled.image(img)
    oled.show()

# Show startup screen
draw_screen(0, 72, 0, False)
print('Display ready. Waiting for serial connection...')

# Try to connect to laptop
ser = None
while True:
    try:
        if ser is None:
            ser = serial.Serial(PORT, BAUD, timeout=1)
            print(f'Connected on {PORT}')
        
        line = ser.readline().decode('utf-8').strip()
        if line:
            # Expected format: wins,total,rounds,connected
            # Example: 68,72,48,1
            parts = line.split(',')
            if len(parts) == 4:
                wins = int(parts[0])
                total = int(parts[1])
                rounds = int(parts[2])
                connected = parts[3] == '1'
                draw_screen(wins, total, rounds, connected)
                
    except serial.SerialException:
        # Cable was unplugged
        ser = None
        draw_screen(0, 72, 0, False)
        print('Cable disconnected. Waiting...')
        time.sleep(1)
    except (ValueError, IndexError):
        pass  # bad line, skip it
    except KeyboardInterrupt:
        break

if ser:
    ser.close()
---CUT HERE---

STEP 5 — ADD SERIAL OUTPUT TO THE SIMULATION
===============================================================

This is the code that runs on YOUR LAPTOP (not the Pi).
It makes the Node.js simulation send data to the Pi
through the USB cable.

5a. FIND THE SERIAL PORT NAME
    When you plug the Pi into your laptop with a USB cable:
    
    On Windows:
    - Open Device Manager
    - Look under "Ports (COM & LPT)"
    - You'll see something like "USB Serial Device (COM3)"
    - Your port name is "COM3" (or whatever number it shows)
    
    On Mac:
    - Open Terminal and type: ls /dev/tty.*
    - Look for something like /dev/tty.usbserial-1234
    
    On Linux:
    - In terminal: ls /dev/ttyUSB*
    - Usually /dev/ttyUSB0

5b. CREATE THE SERIAL BRIDGE SCRIPT
    In your project folder, create a new file:
    tools/pi_bridge.js
    
    Paste this:

---CUT HERE---
// Pi serial bridge — run this alongside the simulation
// node tools/pi_bridge.js COM3   (Windows)
// node tools/pi_bridge.js /dev/ttyUSB0   (Mac/Linux)
import { SerialPort } from 'serialport';
import { readFileSync, watchFile } from 'fs';
import { fileURLToPath } from 'url';
import { dirname, join } from 'path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const portName = process.argv[2];
if (!portName) {
  console.error('Usage: node tools/pi_bridge.js COM3');
  process.exit(1);
}

// Connect to Pi
const port = new SerialPort({ path: portName, baudRate: 9600 });
port.on('open', () => console.log(`Connected to Pi on ${portName}`));
port.on('error', err => console.error('Serial error:', err.message));

// Watch the status file that the simulation writes to
// The simulation writes: wins,total,rounds,connected
const statusFile = join(__dirname, '../data/pi_status.txt');

function sendStatus() {
  try {
    const data = readFileSync(statusFile, 'utf8').trim();
    if (data && port.isOpen) {
      port.write(data + '\n');
    }
  } catch (e) {
    // file not ready yet
  }
}

// Send status every 500ms
setInterval(sendStatus, 500);
console.log('Bridge running. Watching for simulation data...');
---CUT HERE---

===============================================================
TROUBLESHOOTING
===============================================================

PROBLEM: Pi display shows nothing
FIX: Check i2cdetect -y 1 — do you see 3c?
     Check wiring: VCC to Pin 1 (3.3V), not Pin 2 (5V)
     Check I2C is enabled: sudo raspi-config → Interface → I2C

PROBLEM: "No module named adafruit_ssd1306"
FIX: pip3 install adafruit-circuitpython-ssd1306

PROBLEM: Serial port not found on laptop
FIX: Try different port names:
     Windows: COM3, COM4, COM5 (check Device Manager)
     Mac: /dev/tty.usbserial-* or /dev/tty.usbmodem*
     Linux: /dev/ttyUSB0 or /dev/ttyACM0

PROBLEM: Pi display shows "learning alone" even when connected
FIX: The simulation isn't writing to pi_status.txt yet.
     Check serve.py has the /pi_status handler.
     Check data/pi_status.txt exists after a demo run.

PROBLEM: Pi won't boot
FIX: Most common cause is the wrong power supply.
     Must be 5V 3A. Try a different cable.
     
PROBLEM: Can't find /dev/ttyUSB0 on Pi
FIX: Try /dev/ttyACM0 instead in flyhero_display.py

PROBLEM: "Permission denied" on serial port
FIX: sudo usermod -a -G dialout pi
     Then log out and log back in.

PROBLEM: Display text is too small
FIX: In flyhero_display.py, change the font size:
     font = ImageFont.truetype('/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf', 14)
     Add this after "draw = ImageDraw.Draw(img)"
     Change draw.text(...) to draw.text(..., font=font)
