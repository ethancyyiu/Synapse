# Advice budget follow-up: fixed before new runs

This is a follow-up to `advice-budget-protocol.md`, not an independent replication: the 12/46-message outcomes on seeds 100-114 are already known. Preserve those files. The earlier adaptive experience-count pilot (`adaptive-sparse-teaching-report.md`) failed its teacher-specific gate; this study must not relabel that method as a discovery.

## Part 1: message count

Use the existing rule-switch task, teacher/student seeds and seed formulas 100-114, trained teacher gate 58/72, initial Strategy A history, 48 post-switch training rounds, 46 observed-cue opportunities, own-action rewards, unchanged preference learning rule, measured DN spike decoding, and teacher-disconnected 72-game frozen checks at rounds 0, 24, 48. Pilot seed 99 checks the initial 24/36 implementation only; pilot seed 98 checks the expanded four-budget implementation. Neither pilot enters the final estimate. Do not replace failed teacher seeds. Recompute 0-, spaced-12-, and full-46-message scores in the new runner and assert exact agreement with the saved results; preserve the old files.

Budgets are 12, 24, 36, and 46; the 12/46 trained arms replicate prior conditions, while 24/36 and the matched control arms supply new comparisons. For budget B, choose distinct observed-cue ordinals `floor((i+0.5)*46/B)` for i=0..B-1, before training. At those exact positions run (a) trained preference, (b) random preference (keyed independent of cue/outcome), and (c) Fisher-Yates-shuffled trained preferences, preserving the selected action multiset while breaking cue/time alignment. Every arm runs the same 48 rounds and has its own rewards. Save actual sent/decoded counts and per-seed 48-round scores. All final files are write-once in a new directory.

For each budget report mean wins/72, number >=58/72, paired mean differences and 95% percentile bootstrap intervals (10,000 paired seed resamples, fixed PRNG seed 2026111515) against no advice and the stronger of matched random/shuffled controls within each seed. Report seed-level scores. A tested budget counts as *reliable recovery in this sample* only if >=12/15 reach 58/72, mean >=58/72, and the lower paired interval over the strongest matched control exceeds 4 wins. This is a study criterion, not proof of population reliability. Do not infer an exact minimum from four sampled budgets.

## Part 2: timing and student request, conditional on runtime

Use budget 24 on the same 48-round task. Compare early (first 24 opportunities), evenly spaced (Part 1), random timing (select 24 of 46 ordinals by Fisher-Yates with seed `2026111600+s`, fixed before training), and student-requested advice. For the request arm, at the pre-reward 240 ms decision point compute the gap between the two highest scores of Fly B's currently active cue head. Request if the gap is <0.20, a cue is present, and fewer than 24 messages have been sent. This is an uncalibrated margin proxy. Request/no-request is a digital upstream signal outside the simulated neural channel. Count it separately; do not backfill unused budget. The teacher action is still sent through measured DN spikes. The rule cannot read correct actions, future rewards, or teacher preferences. Do not change the student's learning equation.

At each timing schedule compare trained, random, and shuffled teacher actions at the same message times where feasible. For student requests, the trained receiver generates the schedule from its own scores; yoked random/shuffled receivers get that fixed schedule so the content comparison has identical exposure. This yoking does not test whether the control receivers would have requested at the same times. Report actual requests/messages, mean/individual recovery, paired intervals, and the predeclared primary timing contrast (requested trained minus evenly spaced trained). A timing advantage is supported only if the paired 95% interval lies above zero and the requested arm meets the same >=12/15 and mean >=58/72 recovery criteria while using fewer than 24 messages on average. Otherwise report it as unconfirmed or failed. Pilot only for code/runtime; no tuning on final outcomes.

## Integrity and limits

Freeze this protocol before running. No changes to the Science demo, banking app, original result files, controller architecture, or learning rules. No Git operations. If runtime is excessive, complete Part 1 and explicitly leave Part 2 unrun. These synthetic RPS results do not measure biology, banking, or general teacher efficiency. Because seeds 100-114 were used in the preceding study, this follow-up cannot be called fresh held-out confirmation.
