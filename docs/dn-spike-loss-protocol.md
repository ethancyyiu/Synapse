# Prospective DN spike-loss teaching pilot

**Locked before the new simulations.** This is a separate robustness pilot. It does not revise the validated Strategy B action-preference experiments or the prior neural-versus-digital ablation.

## Question and fixed assignments

Does the existing measured-DN teacher channel retain its early, disconnected learning advantage when individual **measured DN spike events** are independently lost? Use the archived reward-trained Strategy B teachers 11013/11014 and their fixed, continuous-state 288-round preference tapes from `data/rps_connectome_contribution_ablation.json`. Pair these respectively with fresh, nonreplaceable student seeds **23001/23002** (not found in the existing documented seed assignments). Reuse that artifact's Strategy B opponent streams: training 82000–82011 / 82012–82023; held-out frozen evaluation 92000, 92001, 92003 / 92004, 92006, 92009. Reuse its globally shuffled, label-independent preference tapes. Teacher weights and tapes, opponent rule, 12×24 budget, 680 ms round, three pooled MBON features, cue-specific external controller, reward update, imitation update, exploration, and KC→MBON multipliers remain fixed.

## Loss and controls

Use loss probabilities **0, 0.10, 0.30**. At 240–280 ms, after each unchanged simulator `net.step()`, inspect actual DN3141/3165 spike IDs. Increment a raw count for every spike. For each such spike, independently keep it with probability `1−loss` using a dedicated keyed RNG (`rng(roundKey + 19001)`) that does not consume neural, opponent, or action randomness. Feed **only retained counts** to the unchanged three-code decoder: rock (positive, zero), paper (zero, positive), scissors (positive, positive), otherwise erasure. No intended action label or raw teacher preference enters the student imitation update. At loss 0, this must reproduce the ordinary measured-count decoding.

Within each student and loss level compare four conditions with identical starting weights, opponent sequences, trial keys, sensory simulation, **reward rule**, and student reward-update opportunities. Realized rewards can differ because policies can choose different actions against the same opponent moves:

1. **Trained neural:** archived trained preference stimulates the existing DNs at 300 Hz; decode retained measured counts.
2. **Matched digital:** no DN stimulation; deliver at 280 ms the exact preference or erasure decoded in the paired trained-neural round. This matches content and message timing, including any wrong decoded code, but uses no simulated spikes in this arm. This direct-digital control is explicitly information-matched to the neural arm.
3. **Shuffled neural:** the previously fixed global shuffle of the archived preference tape uses the same DN stimulation and per-spike loss rule.
4. **Silence:** no message, DN stimulation, or imitation. Compute once per student and share that curve across the three loss comparisons.

Every student performs its own selected-action RPS reward update even on an erased or silent round. An erased code causes no imitation. Do not alter the simulator's spike list, dynamics, connectivity, or model weights. These arms measure the effect of measurement-buffer corruption, not a biological synaptic lesion.

## Checks, measurements, and decision

Run **one focused correctness check** before training: for one fixed DN code and key, verify zero loss retains every measured spike and decodes the intended action; 100% diagnostic loss retains zero counts and produces erasure; in both cases verify the raw spike count is unchanged and no simulator state or weights are modified by the thinning function. The 100% case is a unit check only, not an experimental condition. Stop before the pilot if this or matched-control integrity fails.

Frozen evaluations at **0, 6, 12, 24, 48, 96, 288** training rounds use the same three 24-round held-out opponent streams, exploration off, zero DN stimulation, and all learning off. To avoid resimulating identical frozen neural input for every arm and checkpoint, create one independent reward-free 72-round neural feature tape **per student** with the archived reset and keyed-stream rules. Apply each frozen checkpoint's fixed cue-head weights to that student's saved VPN route and standardized MBON features to obtain its three Q scores and greedy action. This is equivalent to a fresh simulator/controller copy per arm here because KC→MBON weights are fixed, the neural state resets every round, no DN is driven during evaluation, and the opponent's next move does not depend on the student's action. Verify this equivalence in the focused correctness check against archived frozen rows before pilot training. The predeclared early metric is mean frozen **wins/72 at 6, 12, 24, 48**. Save all frozen win curves and 72 trial-level frozen actions per checkpoint, final cue/action counts, raw and retained DN counts, intended and decoded messages, erasures, wrong codes, imitation counts, starting/final controller weights, and integrity checks in a new exclusive-creation JSON artifact.

For each student and loss level, call neural teaching **surviving** only if trained-neural early mean exceeds both its matched shuffled-neural and silence controls by at least **4/72**, and its final disconnected evaluation has at least **58/72 wins**, at least **70% wins per observed cue**, and at least **12 selections per action** across 69 observed-cue rounds. Require both students to pass for a loss level. Call a neural-over-digital advantage only if neural early mean exceeds its matched digital arm by at least **4/72 for both students**; report the final difference separately. Record actual decoding fidelity without imposing a post hoc threshold. A failed correctness or source-tape validity check stops before training; a failed outcome gate is reported without another run or tuning.

The digital arm copies the neural arm's **decoded output**, so exact equality of downstream learning is expected if the directly stimulated DNs have no other causal effect on future student features. Similarity would establish that actual measured spikes transport usable information under this buffer-loss model, **not** superiority over digital delivery, biological memory, bandwidth savings, or general tolerance to other noise.
