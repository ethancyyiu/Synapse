# Locked reward-free package-recovery sensory validation

**Locked  before any new neural probe.** The [practical-transfer teacher gate](practical-transfer-report.md) remains failed. This study only tests whether the already used three-pooled-MBON nearest-centroid *decoder recipe* transfers from reward-free calibration to independent training-style neural streams. It neither trains a controller nor changes stimulation, neural dynamics, action readout, historical outcomes, or the HackPrinceton demo.

## Fixed identities and probe schedule

- Calibration neural seed **17101**. Use exactly **six recordings per cue** to fit the three centroids, plus six disjoint within-seed check recordings per cue. The calibration/check cue order is C0 repeats 0–11, then C1 0–11, then C2 0–11. Keys are `seed*10^7+(2700+12*cue+repeat)*1000+1`, matching the prior sensory key family. Only repeats 0–5 enter centroid means; repeats 6–11 are scored without refitting.
- Independent validation neural seeds **17102** and **17103**, never used in decoder fitting. Each gets exactly **72** probes: 24 of each cue. A fixed Fisher–Yates shuffle of the multiset `[C0×24,C1×24,C2×24]` uses `rng(2026110961)` and `rng(2026110962)` respectively. Probe `i` uses `seed*10^7+i*1000+1`, the prior training-style keyed stream family. Order and keys are fixed before measurement. Total: **180** reward-free probes, with no replacement or extra seeds.
- The frozen numerical centroids in `data/practical_transfer_initial.json` from seed 17001 are an **analysis-only secondary comparator** on the same validation recordings. The **primary locked gate** uses only the fresh 17101 centroids. No centroid, feature scaling, population, threshold, or scoring rule is selected from validation results. The new cross-seed test is stricter than the prior within-seed six-probe check; its outcome does not retroactively change that check.

The search of existing docs/tools found no prior use of seeds 17101–17103 or schedule seeds 2026110961–62. Each probe builds the existing real-wiring `Network` for its designated seed, calls `resetState()` before stimulation, assigns `net.rand=rng(key)`, drives `net.laneVpn[cue].slice(2)` at **150 Hz from 0–240 ms**, calls `resetCounts()` at **50 ms**, then measures counts and features at **240 ms**. The neural state is not carried between presentations. No dopamine/reward, controller action, DN message, or learning update occurs. The same saved RPS `featureMean/featureStd` and original `f_j=(log1p(pooledRate_j)-mean_j)/std_j` apply. Pooled rates are the mean post-reset spike count in each of the existing three MBON groups. The decoder chooses the lowest-index centroid with minimum **squared Euclidean distance** in standardized three-feature space; margin is second-smallest minus smallest distance (zero is a tie). The archived 17001 centroid comparator uses this same feature vector and equation.
